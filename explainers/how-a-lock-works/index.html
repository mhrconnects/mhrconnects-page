How does a key actually open a lock?
Inside the lock
Each chamber holds a spring, a driver pin and a key pin.
Locked
Driver pins cross the shear line, so the plug can't turn.
Wrong key
The pins stop at the wrong heights. Still blocked.
Right key
Every gap lines up exactly on the shear line.
Unlocked
Nothing blocks the plug, so it turns and the lock opens.
Spring
Driver pin
Key pin
That's how a pin tumbler lock works.
